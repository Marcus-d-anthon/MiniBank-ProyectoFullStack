# 💰**Full Stack - Proyecto para la Gestión Bancaria**📊

Este proyecto se basa en la creación de un sistema bancario para la organización y visualización de cuentas bancarias y transacciones entre usuarios. Hace el uso del backend y frontend para su creación, lo que las complementa para la elaboración del proyecto. Usa **Node.js** como su punto de inicio, con ayuda del framework **Express** para maximizar las posibilidades de mejoras a largo plazo y se complementa con MongoDB Atlas con Mongoose para una Base de Datos sólida, capaz de soportar muchos datos entre usuarios, cuentas y transacciones. El backend sigue buenas prácticas de arquitectura, modularización y documentación como está, también aplican conceptos como API REST Full, cliente-servidor, uso de rutas, controladores y conexión con la Base de Datos alojada en la nube. El frontend de la misma forma, hace uso de buenas prácticas de arquitectura y documentación.

---

## 📖 Propósito del Proyecto Full Stack

El Propósito principal del Proyecto es:

- Implementar un servidor REST real y funcional.
- Conectarlo a MongoDB Atlas a través de Mongoose.
- Brindar una buena arquitectura en el Frontend y Backend
- Permitir crear, consultar, actualizar y eliminar usuarios, cuentas y transacciones
- Conectar el Frontend con el Backend

## 📦 Tecnologías Utilizadas

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- React
- Vite
- dotenv
- bcryptjs (Para cifrado de contraseñas)  
- jsonwebtoken (Para autenticación JWT)
